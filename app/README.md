Инструкция по установке и запуску

Описание
Локальное веб-приложение для анализа тональности текстов на русском и английском языках. Обработка данных происходит локально на компьютере пользователя. Приложение включает в себя извлечение текста из файлов, определение языка, классификацию тональности, визуализацию данных и экспорт отчетов.

Системные требования
Операционная система: Windows.
Python версии 3.10 или выше.
PostgreSQL версии 14 или выше.
Подключение к интернету при первом запуске (для загрузки NLP-моделей).

Шаг 1. Подготовка окружения
1. Откройте терминал (командную строку) в корневой папке проекта.
2. Создайте виртуальное окружение:
   python -m venv .venv
3. Активируйте виртуальное окружение:
   .\.venv\Scripts\activate
4. Установите необходимые библиотеки:
   pip install -r requirements.txt

Шаг 2. Настройка PostgreSQL

1. Убедитесь, что служба PostgreSQL запущена.
2. Создайте базу данных для приложения.
   createdb -U postgres -p 5433 sentiment_analyzer
3. В корне проекта создайте файл .env.
4. Откройте .env и укажите параметры подключения к вашей базе данных:
   DATABASE_URL=postgresql+asyncpg://postgres:ВАШ_ПАРОЛЬ@localhost:5433/sentiment_analyzer`
   Замените ВАШ_ПАРОЛЬ на актуальный пароль пользователя postgres.

Шаг 3. Инициализация базы данных

Выполните команду для создания необходимых таблиц (sessions, files, reviews):
python -m app.init_db

Шаг 4. Запуск приложения

Способ 1
Дважды кликните по файлу run.bat в корне проекта. Скрипт активирует виртуальное окружение, запустит сервер и автоматически откроет браузер с нужным адресом.

Способ 2
Выполните в терминале (при активированном виртуальном окружении):
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

После запуска откройте в браузере адрес: `http://127.0.0.1:8000`

Примечание о первом запуске
При первом запуске анализа приложение скачает модели для обработки естественного языка (около 700 МБ) с репозитория HuggingFace. Для этого требуется интернет. После загрузки модели кэшируются на диске, и приложение сможет работать полностью в офлайн.
